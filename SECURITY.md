# Security Policy

## Supported Versions

Security fixes are provided for the latest released version line.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.4.x   | :white_check_mark: |
| < 1.4   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately using GitHub's
[private vulnerability reporting](https://github.com/mahdibohloul/projectreactor.retry.aop/security/advisories/new),
or by email to **mahdiibohloul@gmail.com**.

Include as much detail as you can:

- A description of the vulnerability and its impact.
- Steps to reproduce or a proof of concept.
- Affected version(s).

You can expect an initial response within a few business days. Once the issue is confirmed,
a fix and a coordinated disclosure will be arranged.
